# 해외 자막 음매드 모음 (Subtitled Otomad Archive)

유튜브(YouTube), 네이버 블로그(Naver Blog), 니코니코동화(Niconico) 등에 업로드된 **해외 음매드(Otomad / YTPMV) 한국어 자막 영상**을 한눈에 모아보고 시청할 수 있는 GitHub Pages용 아카이브 웹사이트입니다.

---

## 🌟 주요 기능

1. **유튜브 & 네이버 블로그 동영상 자동 임베드 추출**
   - 상단의 **[영상 추가 / 링크 추출]** 버튼을 누르고 유튜브 주소나 네이버 블로그 영상 소스코드를 붙여넣으면, 자동으로 ID와 플레이어 임베드를 추출합니다.
   - 추출된 동영상은 화면에서 즉시 재생 테스트가 가능하며, `data.json`용 코드가 자동으로 생성됩니다.

2. **다양한 탐색 & 뷰 모드**
   - **연도별 (YEAR)**: 영상 업로드 연도별로 분류하여 연대순 감상
   - **자막/역자별 (SUBTITLER)**: 자막 제작자별 작품 목록 및 모달 팝업
   - **원작자별 (CREATOR)**: 오리지널 음매드 제작자별 모아보기
   - **전체 (ALL)**: 모든 아카이브 영상 그리드 뷰

3. **스마트 정렬 & 실시간 검색**
   - 최신순, 오래된순, 이름순, 랜덤 셔플 정렬
   - 제목, 원제, 원작자, 자막자, 태그, 동영상 ID 통합 실시간 검색

4. **다국어 지원 (i18n)**
   - 한국어(KO) 및 일본어(JA) 원클릭 전환

5. **깃허브 페이지(GitHub Pages) 최적화**
   - 서버 없이 정적 파일(`index.html`, `data.json`)만으로 완벽하게 구동됩니다.

---

## 🚀 GitHub Pages 배포 방법

1. 현재 폴더의 파일들(`index.html`, `data.json`, `README.md`)을 새 GitHub 저장소(Repository)에 커밋 및 푸시합니다.
2. GitHub 저장소 상단 메뉴의 **Settings** 클릭
3. 좌측 사이드바의 **Pages** 클릭
4. **Build and deployment** 항목에서:
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` (또는 `master`) / `/ (root)` 선택 후 **Save** 클릭
5. 1~2분 후 생성되는 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소로 접속하면 아카이브가 즉시 공개됩니다!

## 🛠️ 로컬 편집 서버 및 data.json 자동 덮어쓰기

별도의 텍스트 편집기나 JSON 다운로드/교체 없이, 브라우저 화면에서 직접 영상을 추가·수정·삭제하고 `data.json`에 바로 덮어쓸 수 있는 로컬 서버 기능이 제공됩니다.

### 실행 방법
1. 폴더 내의 **`start_editor.bat`** (또는 **`run_editor.bat`**) 파일을 더블클릭합니다.
2. 로컬 서버(`server.py`)가 구동되며 기본 웹 브라우저가 편집 모드(`http://localhost:8000/?mode=edit`)로 자동 실행됩니다.
3. 웹 화면 상단에 **[🛠️ 편집 모드 활성화됨]** 배너가 표시됩니다.

### 제공되는 편집 기능
- **유튜브 제목 & 원작자 자동 채우기**: 단일 유튜브 영상 주소를 붙여넣으면 영상 제목과 채널명(원작자)이 입력창에 자동으로 쏙 채워집니다.
- **유튜브 재생목록(Playlist) 일괄 추출**: 재생목록 주소(`list=...`)를 붙여넣으면 재생목록 내 모든 영상을 한 번에 자동 추출하여 제목 확인, 자막자 일괄 적용 후 `data.json`에 원클릭으로 덮어쓸 수 있습니다.
- **영상 카드 직접 수정/삭제**: 각 영상 카드 하단의 **[수정]**, **[삭제]**, **[▲/▼ 순서 이동]** 버튼을 통해 즉시 편집하고 `data.json`에 덮어씁니다.
- **영상 추가 및 원클릭 덮어쓰기**: **[영상 추가]** 모달에서 링크를 입력 후 **[data.json에 저장 (덮어쓰기)]** 버튼만 누르면 로컬 파일에 즉시 반영됩니다.
- **`data.json` 원본 직접 편집**: 상단 배너의 **[data.json 직접 편집]** 버튼을 눌러 전체 JSON 코드를 에디터 형태로 수정하고 문법 검사 후 즉시 덮어쓸 수 있습니다.
- **안전 백업 기능**: 데이터를 덮어쓸 때마다 이전 상태가 **`data.backup.json`**으로 자동 보관되어 실수를 방지합니다.

## 🎬 동영상 추가 방법

웹페이지 상단의 **[영상 추가 / 링크 추출]** 버튼을 이용하시면 가장 간편합니다.

### 1. 유튜브(YouTube) 영상 추가
- **단일 영상**: 유튜브 주소(`https://www.youtube.com/watch?v=...` 또는 `https://youtu.be/...`)를 붙여넣으면 ID, 고화질 썸네일은 물론 **영상 제목과 원작자(채널명)가 자동으로 입력**됩니다.
- **재생목록(Playlist)**: 재생목록 주소(`https://www.youtube.com/playlist?list=...`)를 붙여넣으면 재생목록 안의 모든 영상이 리스트로 일괄 추출되며, 번역자/태그를 일괄 지정하여 한 번에 등록할 수 있습니다.

### 2. 네이버 블로그(Naver Blog) 자막 영상 추가
- **방법 1 (동영상 소스코드 붙여넣기 - 추천)**:
  1. 네이버 블로그 본문의 동영상 플레이어 위에서 **마우스 우클릭 → [소스 코드 복사]** 클릭 (또는 영상 우측 상단 공유 아이콘 → HTML 복사)
  2. 추출기 입력창에 그대로 붙여넣기 (`vid`와 `outKey`가 자동 추출되어 아카이브 내에서 바로 재생됩니다)
- **방법 2 (블로그 링크 붙여넣기)**:
  - 블로그 글 주소(`https://blog.naver.com/...`)를 붙여넣으면 네이버 블로그 바로가기 카드가 생성됩니다.

### 3. 변경 사항 저장
- **편집 모드(로컬 서버 실행 시)**: 화면의 **[data.json에 저장 (덮어쓰기)]** 버튼만 누르면 로컬 `data.json` 파일에 즉시 영구 저장됩니다.
- **일반 모드(GitHub Pages)**: 추출기 하단의 **[data.json 다운로드]**를 눌러 최신 파일로 교체 후 깃허브에 커밋/푸시하시면 됩니다.
